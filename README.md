يعطيك العافية دكتور،
أنا خلصت الكود كامل والـ Logic كله شغال عندي، بس للأسف ما قدرت أعمل Run وأوريك النتيجة بسبب مشكلة في جهازي والإنترنت.

الأندرويد ستوديو عندي عم يعطيني خطأ:
`Unexpected lock protocol found in lock file. Expected 3, found 0.`

وهاد خطأ في الـ Gradle وملفات الـ Build المؤقتة، مش من الكود، وبيصير لما ينقطع التحميل أو يعلق الجهاز وهو عم يحمل الـ SDK.

حاولت أعمل Clean ومسحت ملفات الـ Build والـ Gradle، بس المشكلة رجعت لأن النت عندي ضعيف والتحميل ما عم يكمل.

عشان هيك سلمت الملف كامل، والكود فيه كل المطلوب: الـ Validation، و الـ ModeActivity، و الـ TabLayout مع الـ Fragments، و الـ Double Back to Exit.
